# Capturas V3

Registro histórico da V3, incluindo mecanismos OCI posteriormente descontinuados. A [galeria atual](../readme/README.md) corresponde à interface da main e não oferece execução Grype/Trivy.

Capturas reais do Chromium, com banco descartável, repositório de fixture, OSV/CPE fictícios identificados e Semgrep local real. Não representam dados de produção ou uma validação de fontes reais por mocks. A suíte de APIs externas é separada.

A pasta 1440 contém as páginas e evidências de análise; os dashboards também estão disponíveis em 1920/1366/1024/768/390 px. A suíte verifica 18 rotas nas seis larguras; as capturas completas ficam nos artefatos de teste. A galeria V2 original foi preservada.

OCI real foi validado separadamente com Trivy/Grype e imagem pública, em outro banco descartável; as capturas gerais permanecem reproduzíveis com fixtures explícitas.

As capturas `1440/oci-real-trivy.png` e `1440/oci-real-grype.png` mostram os scanners e advisories reais da imagem pública Alpine, em banco descartável separado.
