# Contribuição

Use Python 3.12 e Node 24. Instale com scripts/install.sh ou scripts/install.ps1. Leia AGENTS.md e docs/PRODUCT_SPEC.md.

Execute pytest em backend, Ruff no backend, npm test e npm run build em frontend. Testes de navegação exigem backend ativo e Chromium (CHROMIUM_PATH configura o executável).

Dados simulados ficam apenas em testes. Registre cobertura e limitações explicitamente. Não faça push automático, publique releases ou inclua dados privados nos commits. Licença escolhida: MIT.
